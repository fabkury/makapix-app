## Systemic notes

- **Decimal comma vs. the parser.** Russian (like de, fr, pt) correctly writes ",5", but the mirror-axis field only parses a dot. Fix the parser to accept both (`replaceAll(',', '.')`) rather than teaching Russian users a dot; until then the label must say ".5". Check every numeric input the editor parses with `double.tryParse` (slider value dialog, Levels gamma, ratio) for the same trap.
- **Handle is "имя пользователя", not "имя".** The Mentions texts shorten the handle to "ваше имя", which a Russian reader takes for the display name. Keep the glossary term wherever the @handle is meant.
- **"Загрузка" covers download, upload, and loading.** The glossary makes the ZIP export a "загрузка", the publish button uploads with «Загрузка…», commonLoading is «Загрузка…», and the layers download is also «Загрузка…» while its siblings say «скачать». Inside one screen this is ambiguous. Use скачать/скачивание for anything that comes to the device, отправка for uploads, and keep "загрузка" for loading and the glossary's Downloads list.
- **Tips must quote the option labels.** Most `tip*` messages quote the labels in «» («Порог», «Диагональ», «Медленно»), but some paraphrase them (интенсивность for «Сила», произвольно for «Свободно», unquoted "Сторона, углы и толщина"). The rule in GLOSSARY.md is that tips name options by the same words; a sweep of all `tip*` against `opt*` would catch the rest.
- **Ban vs. block.** The glossary keeps the moderator ban (забанить) apart from the user's Block (заблокировать); the rules screen says "блокируются" for bans. Worth checking every moderator-facing and rules text for "блок…" used in the ban sense.
- Not flagged, for consistency only: "Club" alone is left in Latin script and undeclined (Опубликовать в Club, с Club). It is consistent across the three packs; if it is kept, prefer constructions that avoid declension (в Makapix Club, в клубе Makapix).
