## Systemic notes

- **"untersetzen" for the Slow chip (tipMove, optSlowTip, mirrorMoveAxisBody).** "Untersetzen" is gearbox jargon most users will not know. Replace it with "verlangsamen" (or "bremsen") wherever the Slow chip is explained; the chip label "Langsam" itself is fine.
- **Decimal comma vs. the parser.** The German localization correctly uses decimal commas in prose, but the mirror-axis field parses with `double.tryParse` and fills itself with a dot. A label that tells users to type a comma makes valid input fail silently. Check every numeric-entry label that shows a decimal example the same way, or make the numeric fields accept a comma in comma-decimal locales.
- **"vertraut" (glossary: trusted user).** For a person, "vertraut" means "familiar" or "close", not "trusted". The toast in this pack already says "vertrauenswürdig". Change the glossary entry to "vertrauenswürdig" and update umdTrusted and any other message that uses the term.
- **posten vs. veröffentlichen.** The glossary gives "veröffentlichen" for publish/post (verb), but this pack uses "posten" for the English "Post…" labels (publishTitle, publishHidden, publishAsNew, publishedTitle, commentPostFailed) and "veröffentlichen" for "Publish…". That mirrors the English and reads naturally, so it does not need changing. Record the split in the glossary (posten = casual "post", veröffentlichen = "publish") so later batches stay consistent.
- **Voice of the tool tips.** The tips mix three forms: the infinitive ("Ziehen, um …"), the third person ("Spiegelt die Ebene …", "Macht …") and the du-imperative ("Tippe auf …"). The English mixes too, but in German the switch is more noticeable, sometimes inside one tip (tipEyedropper). Prefer the infinitive for instructions and the third person for what a button does, and drop the du-imperative from the tips.
- **Nominalized verbs in tooltips** ("tippen wechselt", mirrorChipTip) must be capitalized. Check other "tap/hold/drag does X" tooltips for the same slip.
- **Consistent and correct:** "du" is used throughout; the „…“ quotes are right; the spaced ellipsis is used uniformly; placeholders and plural branches are all intact; the glossary terms (Beitrag, Werk, Ebene, Frame, Ebenendatei, Abstammung, sperren/entsperren, empfehlen/Empfehlung aufheben, Freigabe) are used consistently.
