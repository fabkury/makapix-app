## Systemic notes

1. **"Promote / demote" → продвинуть / снять продвижение (glossary).** In Russian social apps "продвижение" is paid promotion (ads, boosting). Here it means a moderator adding a post to the Recommended feed (notifPromoted, artworkMenuPromote/Demote, and modPromote*/modDemote* in pack 2). Change the glossary to "добавить в рекомендуемое / убрать из рекомендуемого" (noun: "рекомендация"), matching feedRecommended "Рекомендуемое".
2. **"Featured" → избранное (glossary).** "Избранное" is the universal Russian word for the user's own Favorites/bookmarks, so the welcome-page heading reads as "your saved items". Use "Подборка" (or "Лучшие работы"; "Лучшее" is already taken by highlights).
3. **"Download" → загрузка (glossary).** In Russian "загрузка" is the everyday word for upload and for loading; the packs already use it for all three (publishUploading, commonLoading, pmd* downloads, layersDownloading), so "Загрузки" on the PMD page is ambiguous with accountUploads "Загрузки" (uploads quota). This pack correctly uses "Скачать" for downloads; make the glossary "скачивание / скачать" and reserve "загрузка" for upload and loading.
4. **Sort labels built as a sentence.** "Сортировать по" + lowercase dative options only works when the options are rendered right after the heading. Use a noun heading ("Сортировка") and nominative capitalized options, which also lets filterFileSize serve as a heading.
5. **Bare "Club".** Russian text cannot use "Club" alone as a noun ("с Club", "в Club"); write "Makapix Club" (or the Russian word "клуб" in lowercase) everywhere the English says "the Club".
6. **"Отменить" for Discard.** Glossary reserves "отменить" for Undo, and "Отмена" is Cancel; using it for Discard makes the discard dialog ambiguous. Use "Не сохранять" / "Сбросить" for discard actions throughout.
7. **Compact day abbreviation.** Use "дн." (timeAgoDays, statUnique7d), the standard Russian abbreviation, instead of "д".
8. **Short tool labels as verbs.** Three tile labels (Осветлить, Затемнить, Отразить) are verbs while the convention is nouns; prefer the noun or a dotted noun abbreviation when it fits.
9. **Fixed noun forms after a number placeholder.** Non-plural messages that put a case-bound noun after `{max}` (mentionCapReached) break for numbers ending in 1–4; rephrase with the number in parentheses or use a plural message.
