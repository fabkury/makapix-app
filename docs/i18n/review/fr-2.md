## Systemic notes

- **Mechanics are clean.** Every `:` `;` `!` `?` carries a no-break space, « » quotes carry inner no-break spaces, every ellipsis is `…`, and all placeholders and plural branches are intact and grammatical (checked by script over all 550 messages). Register is "vous" throughout.
- **Decimal comma in typed input.** French UI text writes ",5", but number fields parsed with `double.tryParse` accept only a dot (mirrorAxisX/Y, high). Any label that tells the user what to type must match what the parser accepts; either keep ".5" in the label or make the parser accept a comma. Displayed numbers that go through `NumberFormat` with the locale (publishLoopSeconds) are fine. German and Russian made the same ",5" change and have the same bug.
- **Handle = "pseudo".** The glossary and the account pages use "pseudo"; the three Mentions settings messages switch to "identifiant", which a French speaker reads as a login ID. Use "pseudo" everywhere for a @handle; keep "identifiant" only for a technical ID (commonNoAccountId is correct).
- **Tool tips mix moods.** About two-thirds of the `tip*` messages use the imperative ("Faites glisser…", "Touchez…", "Réglez…"); the rest use the third-person descriptive ("Retourne…", "Inverse…", "Fait pivoter…"), and tipPlay mixes both inside one tip. Pick the imperative, as the English does, and apply it to every tip.
- **Option names in tips.** Most tips capitalize the on-screen option names (Seuil, Diagonale, Lent, Points, Doux, Brume); a few lowercase them (tipOutline, tipRotate, tipResize). Capitalize them all so the user can match the tip to the chip.
- **Slow (Lent).** optSlowTip says "Démultiplie le geste", which is exact; tipMove and mirrorMoveAxisBody say "affine", which is vague. Use "démultiplie" for every reference to the Slow chip.
- **Draft = "ébauche".** Used well in optSlowTip and optRotateHint; tipCopyPaste paraphrases it away. Keep the term wherever the English says draft.
